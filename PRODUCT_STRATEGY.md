# e-Lesson — Стратегия продукта

## Целевая аудитория

**Тип:** Языковые школы, репетиторы, подготовка к экзаменам в Ташкенте

**Проблемы клиентов:**
- Учёт в Excel и бумажных тетрадях
- Потеря данных о платежах и учениках
- Сложно отслеживать посещаемость и прогресс
- Нет онлайн-доступа для учеников
- Ручная работа с платежами и чеками

---

## Что предоставляет e-Lesson

### 1. Автоматизация учёта (главная ценность)

| До (без e-Lesson) | После (с e-Lesson) |
|---|---|
| Excel-таблицы с учениками | Автоматический профиль ученика |
| Бумажные квитанции | Загрузка чеков через сайт |
| Ручной расчёт платежей | История платежей в одном месте |
| Забытые группы/курсы | Структурированные курсы и материалы |
| Телефонные звонки для напоминаний | Автоматические уведомления |

### 2. Онлайн-платформа для учеников

- Доступ к курсам и материалам 24/7
- Прохождение тестов онлайн
- Просмотр результатов
- Личный кабинет с балансом и баллами

### 3. Управление из любого места

- Админ-панель доступна с телефона
- Централизованное управление студентами
- Контроль платежей и подписок

### 4. Профессиональный вид

- White-label (ваш логотип, цвета)
- Собственный домен (school.e-lesson.uz)
- Современный дизайн для учеников

---

## Что решает e-Lesson

| Проблема | Решение |
|---|---|
| Нет учёта учеников | Автоматические профили, подписки |
| Сложно управлять платежами | Система загрузки чеков, одобрения |
| Нет онлайн-доступа | Студенческая платформа с курсами |
| Ручная работа с тестами | Создание и проверка тестов онлайн |
| Сложно отслеживать прогресс | Результаты тестов, лидерборд |

## Модель монетизации (рекомендация)

### Вариант 1: Абонентская плата за центр (рекомендуется)

**Ценообразование:**
| План | Цена | Что включено |
|---|---|---|
| Базовый | $30-50/мес | До 50 учеников, 5 курсов, базовые функции |
| Стандарт | $80-120/мес | До 200 учеников, неограниченные курсы, аналитика |
| Премиум | $150-250/мес | Неограниченно, белая метка, приоритетная поддержка |

**Преимущества:**
- Предсказуемый доход
- Простая модель для клиентов
- Масштабируется с ростом центра

### Вариант 2: Платные функции (дополнение)

- Дополнительные ученики за плату
- Расширенная аналитика
- Приоритетная поддержка
- Кастомные интеграции

## Что клиенты будут платить

### Основные функции (включены в базовый план)

1. **Управление студентами**
   - Автоматическая регистрация
   - Профили учеников
   - Подписки на курсы

2. **Управление курсами**
   - Создание курсов и материалов
   - Загрузка видео и файлов
   - Тесты и вопросы

3. **Платежи**
   - Загрузка чеков
   - История платежей
   - Уведомления в Telegram

4. **Студенческая платформа**
   - Доступ к курсам 24/7
   - Прохождение тестов
   - Просмотр результатов

### Платные функции (дополнительно)

1. **Расширенная аналитика** — $10-20/мес
   - Детальная статистика по ученикам
   - Отчёты по успеваемости
   - Прогноз оттока

2. **Приоритетная поддержка** — $15-25/мес
   - Выделенный менеджер
   - Быстрое решение проблем
   - Обучение персонала

3. **Кастомизация** — $50-100 (разово)
   - Свой логотип и цвета
   - Собственный домен
   - Настройка под бренд
